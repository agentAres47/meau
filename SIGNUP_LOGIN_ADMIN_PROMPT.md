## 1\. Admin Page

Create an admin page/dashboard with the following capabilities:

* **DL Approval Queue:** Show how many people have uploaded a driver's license (DL) pending approval. Give the admin access to **Approve** or **Decline** each submission.
* **User Profiles:** Show profiles of every person who has logged in.
* **Network/Usage Monitoring:** Let the admin check network traffic / app usage — a dashboard view showing how heavily the app is being used (e.g. active users, request volume, load).
* **Extensibility:** Leave room to add further admin capabilities/suggestions beyond the above as needed.

## 2\. Post-Signup Profile Details

Once a user successfully signs in for the first time, prompt them to fill in:

* **Name**
* **Phone Number**
* **Sex**
* **Role:** Student / Faculty / Staff (selectable)
* **Department:** dropdown populated with the list of departments
* **Profile Photo:** option to add one
* **Driver's License Upload:** optional — only needed if the user wants to also register as a driver. **Skippable.**
